# HandBrake - A Smaller Copy of a Video You Own

## Departure

The source is a file on a disk you can open, not a protected disc in a drive.
You know the folder where the new file should land, and that folder has room for a full extra copy.
The original stays where it is until the new file plays.
You are not in a hurry to queue twenty titles. One clip proves the settings.

## Weather

A phone video and a screen recording do not want the same bitrate.
Dark, noisy footage falls apart if you squeeze it too hard. A talking-head recording can go smaller.
If the source is already a small web file, converting it again mostly loses detail.
Match the preset to the picture you can see, not to a number from a forum.

## Fuel

Pick a preset you can name, such as a general "fast" or "HQ" option the current build shows.
Leave exotic filters off for the first encode.
Set the destination to a different file name so you cannot overwrite the source by accident.
Start the queue and let that one job finish.

## Heading

Open the new file in a normal player.
Scrub to a face, some text, and a minute of motion.
If text is mush or faces block up, the bitrate is too low. Encode again from the original with a higher quality, and delete the bad copy.
If it looks like the source and the file is smaller, the settings are good enough to reuse on similar clips.

## Cruise

Use the same preset on the next similar file, not on a different kind of footage.
Keep the originals until you have watched the conversions you care about.
A batch overnight is reasonable only after one file from that batch has already looked right.
Do not point the output folder at the only copy of the source folder.

## Diversion

The encode fails immediately. The file may be incomplete, or it is not a video HandBrake can read. Do not "fix" it by installing a ripping tool.
The result has no sound. Check the audio track in the source. If the source is silent, the conversion did not delete the sound.
The result is larger than the source. You chose a heavy preset for a file that was already compressed. That is waste, not quality.
The job sits at zero. The disk is full or the destination is a drive that fell asleep. Free space or wake the disk, then start one job again.

## Approach

Write down the preset name and the kind of footage it suited.
Keep a short note if you had to raise quality for screen text.
The originals can move to a backup disk after you have sampled the new files.
HandBrake does not need to stay open once the queue is empty.

## Landing

Close the window.
The new files play.
The sources you still need are still on disk.
A failed experiment is deleted so you do not later think it is the good copy.

## Not this flight

This is not a DVD ripper and not a Blu-ray decrypter. Do not go looking for how to strip those locks.
It is not a download manager.
It is not an editor for cutting a story together. An editor does that, then you can compress the export.
Someone else's private video is not a file you convert because you found it.
A codec pack is not required to open the result in a normal player.

## Next leg

The next similar clip uses the preset you already watched.
A new camera means a new ten-second test.
After an update of HandBrake, convert one known file before a long queue.
If the new build looks worse, return to the version that matched your note.

## Logbook

Source type, preset, and whether you kept the original.
Destination folder.
One sentence on whether text stayed readable.
Date, if this setting is the one you will reuse.

## Tower

You are converting your own footage.
A work machine may not want a long encode. Ask before you fill the disk.
Do not upload the result anywhere the source was not yours to share.
Uninstall leaves both the originals and the copies. Delete the copies yourself if they should not remain.
